# Does compression change behavior?

When an LLM agent's context is compacted (summarized, trimmed, rewritten),
does the agent still do the same thing? We measure it directly: give the
same model the full history and a compressed history, sample its next
actions from both, and count the disagreement - always against the noise
floor of sampling twice from the identical context.

The paper-facing results use only trajectories generated by our own agents.
Every result JSON is in `experiments/results/`; the full disposition of all
experiments is in [EXPERIMENT_LEDGER.md](docs/EXPERIMENT_LEDGER.md).

## Current findings (powered on-policy evidence)

| finding | numbers | experiment |
|---|---|---|
| **Verbatim recency is nearly free at a 25% budget.** | logged-action agreement: full 0.65, keep-recent 0.66, summary 0.46 (N=25) | exp8 |
| **A tiny extractive core remains useful.** | 0.57 agreement at 2%; 0.68 at 25% (N=25) | exp17 |
| **The robust boundary is verbatim vs rewritten—not skeleton vs recency.** Raw skeleton+tail and keep-recent tie; canonical one-liners and summaries lose. | pooled skeleton advantage +0.037, p=0.39; rewriting costs about 13 points | exp21, exp23 |
| **Off-policy laws may not transfer.** The block/freeze and wrapper effects looked strong on public traces but vanish on our agent's trajectories. | freeze p=0.78; wrapper p=0.36 | exp4, exp21 |
| **Containment is a weak supporting predictor.** | on-policy rho=-0.23 vs NLL=-0.12 | exp20 |
| **Sampled tool-level distortion needs a noise floor.** | exact TV 0.029 vs 8-sample estimate 0.275 | exp19 |

The deployable behavioral rule is: **copy exactly; do not paraphrase action
history.** We do not claim skeleton+tail beats keep-recent.

**Retractions and nulls matter here.** All pre-Aug-6 Terminal-Bench scores are
retracted because the offline verifiers never executed. The verifier repair
and a positive oracle reward are now validated, but task-success effects have
not yet been measured. The powered Qwen format rerun is null (0.47 native vs
0.48 wrapper), and DPO training is null at the tested dose.

**Honest limit:** logged-action agreement measures behavioral fidelity, not
optimality. The sole next objective is exp22, which tests the live compaction
arms against valid task success. See [ICLR_PLAN.md](docs/ICLR_PLAN.md).

## Quickstart

```bash
pip install -r requirements.txt
python tests/run_tests.py                 # no GPU needed
cd experiments && bash run_all.sh cpu     # analyses, minutes

# with a GPU (A100-40GB+; H100 recommended):
HF_HOME=... python ../prefetch.py         # cache models (internet needed once)
bash run_all.sh gpu                       # or: run_all.sh queue (Slurm)
```

The method in one paragraph: for each example we hold out the recent turns,
compress the older history with the compressor under test, then sample 8
next actions from (compressed + recent) and 8 from the full context.
Distortion D is total variation between the two action distributions at
three granularities (tool / tool+verb / exact args), floor-referenced
against a full-vs-full resample, with paired permutation tests across
examples. On-policy traces come from our own TB2 runs (`tb2/`); grounded
agreement compares sampled actions to the action the agent actually took.
