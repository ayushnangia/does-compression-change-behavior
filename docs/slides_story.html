Does compression
change behavior?

When an agent's memory gets compacted,
does it still do the same things?

Agents forget.

Long tasks overflow the context window.

So every system does the same thing:
summarize the old history, keep going.

And everyone checks the summary the same way:
did the facts survive?

We ask a different question.

Not "are the facts still there?"

Would the agent still take the
same next action?

A perfect compaction is invisible:
the agent behaves as if nothing was removed.

The test

Freeze a real agent mid-task.
Compress its memory.
Ask it: what do you do next?

The original run already recorded the true answer.
We count how often they match.

Summaries fail this test.

How often the agent repeats its real next action:

full memory: 65%
just keep recent tokens: 66%
LLM-written summary: 46%

The default in every product is the worst option we measured.
Doing almost nothing beats it. This survived every replication we threw at it.

Copy exactly. Never paraphrase.

Same information, same size budget:

Byte-exact copies of the agent's past commands keep its behavior.

The same commands rewritten as tidy one-liners lose 13 to 20 points.

The rewriting was our own idea. The experiment rejected it.

Format cliffs

The same summary, delivered in a different wrapper:

one model works fine (0.75),
another outputs gibberish (0.00).

There is no universal compaction format.

The training mismatch

In a long task, memory is compressed many times.
The first compression does nearly all the damage.

But RL training schemes give that first summary
the least learning signal (13.5% of the last one's).

The one that hurts most learns least.

We replicated ourselves.

Everything was first measured on public traces of other models.
Then re-measured on our own agents' real trajectories.

Survived: summaries worst, copy-exactly, the metric itself.

Did not survive: two of our early laws.

Measure compaction on your own agent,
not on borrowed traces.

What's next

Tie compression to task success directly, in live episodes.

Finish re-measuring everything on our own trajectories.

Can the behavior score train a compressor?
First try: no effect. Bigger try queued.

Keep the behavior,
not just the facts.
